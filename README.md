# kknote

모눈 종이 위에 쓰는 개인용 Mac 메모장. 메모는 직접 삭제할 때까지 남아 있습니다.

## 실행

`dist/mac-arm64/kknote.app`을 열거나 Applications 폴더로 옮겨 사용합니다. Apple Silicon, macOS 13 이상을 대상으로 빌드합니다. Developer ID 서명과 Apple 공증은 포함하지 않습니다.

| 단축키 | 동작 |
| --- | --- |
| ⌥A | 다른 앱에서 열기 / 맨 앞에 있으면 저장 후 숨기기 |
| ⌘⇧[ / ⌘⇧] | 이전 / 다음 메모 (양 끝에서 순환) |
| ⌘N | 맨 뒤에 새 메모 추가 후 바로 입력 |
| ⌘K | 선택한 글자의 링크 삽입 / 편집 |
| ⌘B / ⌘I / ⌘U | 굵게 / 기울임 / 밑줄 |
| ⌘Z / ⌘⇧Z | 실행 취소 / 다시 실행 |
| ⌘클릭 | 링크를 기본 브라우저에서 열기 |
| Esc / ⌘W | 창 숨기기 |
| ⌘Q | 저장 후 앱 종료 |

줄 처음에 `# `, `## `, `### `, `- `, `1. `, `[] `, `- [ ] `, `- [x] `, `> `, 코드 펜스(백틱 세 개)를 입력하면 서식으로 바뀝니다. `**글자**`, `*글자*`, `~~글자~~`, 인라인 코드도 지원합니다. `- [ ] `는 미완료, `- [x] `는 완료 체크박스가 됩니다. 상단 `…` 메뉴에서도 서식을 선택할 수 있습니다.

창 모서리로 크기를 조절할 수 있고, 마지막 위치와 크기를 기억합니다. 창을 닫아도 앱은 메뉴 막대에 남아 있습니다. ⌥A가 다른 앱과 충돌하면 해당 앱의 단축키를 해제한 뒤 kknote를 다시 실행합니다.

## 저장

로컬의 `~/Library/Application Support/kknote/notes.json`에 자동 저장합니다. 하단의 저장 상태를 확인할 수 있으며 오류가 나면 재시도할 수 있습니다. 창을 숨기거나 종료하기 전에도 저장을 기다립니다. 오래된 메모의 자동 삭제, 서버 전송, 클라우드 동기화는 없습니다.

앱 메뉴의 **저장 폴더 열기**로 원본에 접근할 수 있습니다. 백업하려면 앱 종료 후 폴더를 복사합니다. 손상된 메모 파일은 자동으로 덮어쓰지 않고 안내 화면을 표시합니다. 메모 삭제는 확인 후 영구 적용됩니다.

## 개발

Node 24를 사용합니다.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run test:e2e
npm run dist
```

E2E는 실제 Electron 앱과 임시 저장 폴더를 사용합니다. 사용 중인 앱이 ⌥A를 점유하지 않도록 종료한 뒤 테스트합니다. 자동화된 조합 이벤트 테스트는 실제 한글 입력기를 통한 수동 검증을 대신하지 않습니다.

아이콘 재생성:

```sh
swift scripts/generate-icons.swift resources
iconutil -c icns resources/icon.iconset -o resources/icon.icns
```

`KKNOTE_DATA_DIR` 환경변수를 지정하면 별도 저장 폴더로 실행할 수 있습니다. 개발 및 검증용입니다.
