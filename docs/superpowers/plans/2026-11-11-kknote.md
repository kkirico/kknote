# kknote Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 개인 Mac에서 실행할 수 있는 영구 보관 메모 앱을 만든다.

**Architecture:** Electron 메인이 파일 저장과 창/단축키를 담당한다. 제한된 preload API로 React + Tiptap 편집기에 연결한다.

**Tech Stack:** Electron, React, TypeScript, Tiptap, Vite, electron-builder, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-11-kknote-design.md`

## Global Constraints
- 앱 이름 kknote, macOS 전용. 서명/공증과 자동 업데이트 제외.
- 모눈 배경과 둥근 창. ⌥A 전역 호출, ⌘⇧[ / ⌘⇧] 메모 이동.
- 노션식 편집과 문자열 링크. 메모 자동 저장, 자동 삭제 없음.
- Node 접근은 메인에 한정. 제한된 preload API 사용.

## Review Focus
- 한글 조합 중 스페이스/Enter가 내용을 손상하지 않아야 한다.
- 빠른 전환/종료 직전 입력을 잃지 않아야 한다.
- 손상된 저장 파일을 빈 내용으로 덮어쓰지 않아야 한다.
- 위험한 링크가 실행되거나 앱 창을 이동시키지 않아야 한다.
- 모니터 구성이 바뀌어도 창을 찾을 수 있어야 한다.

## 검증 결과

Node 24에서 타입 검사, 단위 테스트 16개, 실제 Electron E2E 11개가 통과했다. ad-hoc 서명을 적용한 Apple Silicon .app 패키지의 codesign 검증과 패키지 자체 실행도 통과했다. 전역 단축키 등록을 확인했으며 실제 OS 키 입력은 미검증이다. 실제 macOS 한글 입력기를 통한 수동 확인과 실행 중 모니터 분리도 미검증이다. Chromium IME 조합 중 이동/종료 보존은 자동 테스트로 확인했다. 커밋과 외부 게시 없이 지정 폴더에 보존했다.
