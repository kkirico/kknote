# kknote 설계

## 목적
Antinote의 간결한 화면을 유지하면서 노션식 편집을 제공하는 개인용 Mac 메모 앱. 계산, 환율, 타이머, OCR은 만들지 않는다.

## 확정 요구사항
- 앱 이름과 프로젝트 경로: kknote, ~/Projects/kknote.
- 밝은 종이색, 은은한 모눈, 둥근 창, 넉넉한 여백. 승인받은 브라우저 시안을 기준으로 한다.
- 창 크기를 자유롭게 조절하고 마지막 크기와 위치를 복원한다.
- ⌥A로 다른 앱에서도 메모 창을 열고 포커스한다. 메모 창이 맨 앞에 있으면 저장 후 앱을 숨겨 이전 앱으로 돌아간다.
- ⌘⇧[ / ⌘⇧]로 이전/다음 메모를 전환한다.
- 노션처럼 마크다운 입력 문법이 바로 서식으로 변환된다.
- 선택한 문자열에 링크를 넣고 ⌘K로 편집한다.
- 메모를 자동 저장하고 앱 재시작 후 복원한다. 오래된 메모는 자동 삭제하지 않는다.

## 구현자가 선택한 기본값
Electron + React + TypeScript + Tiptap. 개인 Mac에서 실행 가능한 .app 배포본을 목표로 한다. Apple 서명/공증과 자동 업데이트는 이번 범위에서 제외한다.

편집 범위는 제목 1~3, 일반 문단, 굵게/기울임/취소선, 글머리/번호 목록, 체크리스트, 인용, 인라인 코드, 코드블록, 수평선, 링크, 실행 취소/다시 실행이다. 노션의 데이터베이스, 협업, 블록 드래그, 슬래시 메뉴는 제외한다. 한글 조합 입력을 보존한다.

메모는 생성 순서로 유지하고 양 끝에서 순환한다. 하단에 현재 번호/전체 수와 이동 버튼, 상단에 새 메모와 메뉴를 둔다. 새 메모는 마지막에 추가한다. 메뉴에서 명시적으로 삭제할 수 있고 확인을 받는다. 마지막 메모를 삭제하면 빈 메모 하나를 만든다. Esc는 창을 숨기고 창 닫기는 종료 대신 숨긴다. 앱 종료는 메뉴 또는 ⌘Q로 한다. 메뉴 막대 아이콘으로 다시 열기와 종료를 제공한다. ⌥A 등록 실패는 사용자에게 알린다.

본문과 메모 목록은 Electron 메인 프로세스를 통해 사용자 Application Support 아래 JSON 파일에 저장한다. 렌더러에는 Node 접근을 제공하지 않고 제한된 preload API만 노출한다. 임시 파일 후 rename으로 저장하며 쓰기를 직렬화한다. 디바운스된 저장은 메모 전환/창 닫기/앱 종료 전에 반영한다. 손상된 파일은 보존하고 복구 안내를 표시한다. 저장 실패를 저장 완료로 표시하지 않는다. 클라우드 동기화와 외부 서비스 연동은 없다.

외부 링크는 http/https/mailto만 시스템 브라우저로 연다. 앱 창 안에서 외부 페이지를 로드하지 않는다. 체크박스 상태와 모든 편집 서식도 저장한다. 창이 화면 밖으로 나간 경우 현재 화면 안으로 복원한다.

## 검증
메모 전환/생성/삭제, 저장 및 재시작 복원, 손상 파일/저장 실패, 링크 검증을 자동 테스트한다. 실제 편집기에서 입력 규칙/체크리스트/링크/한글 입력을 확인한다. Mac 앱에서 전역 호출과 창 상태 복원을 확인한다. 실행하지 못한 검증은 명시한다.

## 추가 요청 반영

⌘N은 현재 위치에 관계없이 맨 뒤에 새 메모를 추가하고 즉시 편집기로 포커스한다. 체크리스트는 `[] ` 외에도 표준 마크다운 `- [ ] `, `- [x] `로 입력하며 완료 상태까지 반영한다.
